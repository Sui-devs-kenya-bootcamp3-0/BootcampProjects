# Bootcamp Projects Submission Guide

Welcome to the Sui Devs Kenya Bootcamp! This guide will help you commit your projects and class assignments to the official Bootcamp Projects repository.

## Repository URL

```
https://github.com/Sui-devs-kenya-bootcamp3-0/BootcampProjects.git
```

## Steps to Commit Your Work

1. **Clone the repository**

   Open your terminal and run:

   ```
   git clone https://github.com/Sui-devs-kenya-bootcamp3-0/BootcampProjects.git
   ```

2. **Create a new branch**

   Create a branch starting with your name to keep your work organized. For example, if your name is John Doe, you can create a branch like:

   ```
   git checkout -b john-doe-feature
   ```

   Replace `john-doe` with your actual name and `feature` with a description of your work if you want.

3. **Add your project files and assignments**

   Copy your project files and class assignments into the cloned repository folder.

4. **Commit your changes**

   Stage and commit your changes with a meaningful message:

   ```
   git add .
   git commit -m "Add project and assignments for John Doe"
   ```

5. **Push your branch to the remote repository**

   Push your branch to the GitHub repository:

   ```
   git push origin john-doe-feature
   ```

6. **Create a Pull Request (optional but recommended)**

   Go to the GitHub repository page and create a Pull Request from your branch to the main branch to submit your work for review.

---

If you have any questions or need help, feel free to reach out to the bootcamp instructors.

Happy coding!
